# Dependencies, split by what you actually want to run.
#
# ---------------------------------------------------------------------------
# The MCP server (src/) needs NOTHING.
# ---------------------------------------------------------------------------
# JSON-RPC 2.0, the MCP lifecycle, the NDJSON framing and the HTTP transport
# are all implemented by hand, as the assignment requires: no official MCP
# SDK, no FastMCP, no protocol library of any kind. The server runs on a bare
# Python 3.11+ install using only the standard library:
#
#   json, sqlite3, sys, os, pathlib, dataclasses, typing, enum, logging,
#   datetime, random, argparse, threading, uuid, http.server
#
# So this works with no installation at all:
#
#   python -m src
#   python -m src --http
#
# ---------------------------------------------------------------------------
# The chatbot (chatbot/) needs these two.
# ---------------------------------------------------------------------------
# Neither one implements MCP. The prohibition in the assignment is on protocol
# libraries; these are the LLM client and an official Anthropic server.

# The Anthropic API client, used to talk to Claude. This is the LLM SDK, not
# an MCP SDK: chatbot/mcp_client.py and chatbot/http_client.py speak the
# protocol themselves, reusing src/jsonrpc.py.
anthropic==1.4.0

# The official Git MCP server from Anthropic, which the assignment asks the
# chatbot to consume. It brings the MCP SDK in as its own dependency; that SDK
# is used by Anthropic's server, never by this project's code.
mcp-server-git==2026.8.18
